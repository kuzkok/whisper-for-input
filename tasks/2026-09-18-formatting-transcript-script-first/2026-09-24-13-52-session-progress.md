- Baseline: кэш-чтение ~74k на каждом вызове (обвязка CLI из кэша), но кэш-запись 29–33k и выход 18–22k токенов на каждом вызове — почти весь выход thinking (ответ ~600 слов). В envelope `num_turns: 3` (structured output идёт через внутренний tool-цикл).
- Время вызова почти не зависит от размера чанка (110–160 с) — его съедает thinking; поэтому последовательный прогон при 20 строках вдвое дольше, чем при 40.
- Новая политика читается заметно лучше baseline: вопросы, кавычки, тире, ASR-правки («ганинга Крюгера» → «Даннинга-Крюгера», «нозг» → «мозг», «fullта» → full-time).
- v1 (40 строк) пересказывала: сжатие перечисления («водить машину / проектировать систему / писать код» → «эти вещи»), синонимы («делаю что-то» → «выполнение чего-то»), смена времени глаголов, «мне лучше вот это» → «мне кажется, это лучший вариант», перестановки частей предложения.
- v2 (40 строк) выбросила два целых предложения, которые v1 на том же месте сохранила (про творческие задачи и про MCP/USB), — разброс между прогонами больше эффекта правки промпта.
- 30 строк: провал схемы `buffer` — один чанк записал 36 слов и потерял 316; это дефект контракта, не размера.
- 20 строк: текст целый, примеры пересказа v1/v2 на месте дословно. Обратный крен — модель стала осторожной и оставляет часть паразитов («Вот все говорят…», «для кого-то, а, проектировать»).
- Отчёт потерь ловит реальные пропуски (v2 chunk 1: −60 с `usb`×2, `mcp`) — детектор работает, но выход с дырой записывается с rc 0.

## Замечания для следующего агента

- Разброс haiku между прогонами больше эффекта правки промпта: v1 и v2 на одном тексте теряли разные куски. Выводы — только по нескольким прогонам и по воспроизводимости дефекта (риск из анализа подтвердился).
- Ошибка этой сессии: в v2 в промпт был вписан запрет «не Даниэль Канеман — имени Даниэль не произносили», а в исходнике прозвучало «по имени Каниман Даниэль». Исправлено на «Каниман» → «Канеман», «ганинга Крюгера» → «Даннинга — Крюгера». Примеры для промпта сверять с исходником, а не с diff: difflib на перестановках показывает ложные «выпадения».
- difflib-метрика «выпавшие куски ≥5 слов» считается скриптом-однострочником по `ft._tokens` исходника и выхода; перестановки дают в ней ложные срабатывания, мультимножественный отчёт потерь их не видит — смотреть оба.
- `FILLERS` включает «а», «вот», «ну», «значит» целиком по числу вхождений во входе: смысловая потеря таких слов в отчёт не попадёт — сознательный размен ради малого шума.
- Константу `CHUNK_LINES` для экспериментов подменять при запуске (`import format_transcript as ft; ft.CHUNK_LINES = N; ft.main()`), не править файл.
- Стоимость сравнивать в одном состоянии кэша: правка `chunk-prompt.md` сдвигает префикс (v2 chunk 1: кэш-запись 62k против ~32k).
- Лекция публичная — цитаты из неё допустимы в промпте и документах задачи; приватные записи — нет.
- Вне скоупа по анализу: `--bare`, тесты с фейковым `claude -p`, смена пути запуска в transcript-cleanup.
