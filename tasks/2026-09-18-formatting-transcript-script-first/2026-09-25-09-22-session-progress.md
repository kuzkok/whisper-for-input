## Что сделано в этой сессии

Пункты плана прошлой сессии не брали. Повод сессии — расход лимита подписки: полный файл лекции (10621 слово) — 35 чанков, по журналу эталона ~18k выходных токенов на чанк, ~$5.5–6 по счётчику CLI, то есть примерно шесть эталонных прогонов. Пользователь предложил проверить модели через свой роутер litellm, где слоты Claude мапятся на другие модели.

### Флаги запуска
- `formatting-transcript/format_transcript.py`: `main()` переведён на argparse (ошибка аргументов — по-прежнему rc 2). Новые необязательные флаги, без них поведение прежнее:
  - `--model <слот>` (по умолчанию `haiku`);
  - `--settings <файл>` — передаётся в `claude --settings` как есть (настройки поверх основных, в т. ч. блок `env` с `ANTHROPIC_BASE_URL`); несуществующий файл — rc 2;
  - `--workers <N>` (по умолчанию 3, раньше только константа);
  - `--budget <USD>` — порог `--max-budget-usd` на вызов (по умолчанию 0.50);
  - `--timeout <с>` — таймаут вызова (по умолчанию 420).
  Значения задаются через module-level константы (`MODEL`, `SETTINGS`, `PER_CALL_BUDGET_USD`, `PER_CALL_TIMEOUT_S`), которые `main()` перезаписывает из аргументов; `format_all_chunks` получает `args.workers`. Нулевые и отрицательные `--workers/--budget/--timeout` отклоняются.
- `call_haiku` переименован в `call_model`.
- Ошибки: в сообщение при rc != 0 и при `is_error` добавлен `subtype` envelope (например `error_max_budget_usd`). `subprocess.TimeoutExpired` печатается как «таймаут N с» — раньше `str(e)` выводил всю командную строку с промптом, килобайты в stderr.
- `formatting-transcript/SKILL.md`: строка про необязательные флаги (с пометкой «без просьбы пользователя не передавать»), в Failure modes — строка про `error_max_budget_usd` → поднять `--budget`, строка про исчерпанные попытки — поднять `--timeout`, если в попытках таймаут.

### Роутер
- Настройки роутера у пользователя — отдельный файл `~/.claude/skyori.settings.json` (блок `env`: `ANTHROPIC_BASE_URL`, токен, маппинг слотов). Слоты: `haiku` → `qwen3-coder-128k:30b` (по словам пользователя, фактически под этим именем сейчас Qwen3-Coder-Next-FP8, 80B; админы роутера переиспользуют имя под обновляемые модели), `sonnet` → `GLM-5.3-Flash`, `opus` → `GLM-5.3`.
- Через роутер CLI не знает тарифа моделей (`costBasis: unknown`) и считает около $5 за 1M входа; кэш префикса частичный (у GLM 32–65k из кэша на вызов, у Qwen 0). Вызов на чанк у GLM ~$0.3–0.5 по счётчику и до 3 внутренних ходов `claude -p` (`num_turns`), так что порог 0.50 на грани — прогоны шли с `--budget 5`.
- GLM отвечает медленно: вызов ~240 с, один вызов не уложился в 420 с — прогоны шли с `--timeout 900`.
- Первая попытка на GLM упала с `rc=1` и пустым `result`; причина не установлена (тогда `subtype` ещё не печатался). Отдельный повтор того же чанка прошёл за $0.36.
- Пользователь видит в логах litellm серию упавших запросов, при том что у скрипта во всех прогонах Qwen и во втором GLM ретраев не было. Предположительно служебные запросы самого `claude -p` (подсчёт токенов, фоновые вызовы); не разобрано — нужен путь и текст ошибки из лога litellm.

## Что подтверждено

Эталон — `extra/lecture-3chunks.txt` (1791 слово, 6 чанков, 5 швов). Команда: `--settings ~/.claude/skyori.settings.json --budget 5 --timeout 900`, слот `sonnet` для GLM, `haiku` для Qwen.

|---|---|---|---|---|---|---|
| haiku с thinking (прошлая сессия) | 559 с | 14–21k | 1676 (−6.4%) | −39 | 2, 12 слов, фальстарты | 2 / 14 |

| GLM-5.3-Flash r2 | 827 с, без ретраев | — | 1722 (−3.9%) | −28 | 1, тот же фальстарт | 3 / 22 |
| Qwen3-Coder-Next r1 | 92 с | ~600 | 1779 (−0.7%) | −26 | 0 | 12 / 19 |

- GLM стабилен между прогонами: швы целые (ручная проверка всех 5 в обоих), вставок текста без соответствия в исходнике нет, «он сейчас, наверное, есть — Андерс Эрикссон» и «Канеман Даниэль» сохранены в словах и порядке говорящего (у haiku тут были сжатие и перестановка). Заминки убирает полностью, «вот» оставляет чаще haiku.
- Qwen работает без рассуждений и нарушает политику в обоих прогонах: добавляет несказанное («мотивации нету» → «Нет ни мотивации, ни желания сделать всё правильно»; «наверное, ещё есть»; «Канеман, Даниэль Каниман»), дублирует текст из контекста соседа («был такой товарищ» дважды в r2), сворачивает перечисление (r2), паразитов почти не удаляет. Отсюда положительная дельта слов.
- Вывод по одному эталону и двум прогонам на модель: для этой задачи через роутер годится только GLM-5.3-Flash (слот `sonnet`), Qwen3-Coder-Next — нет.
- Проверки аргументов: без аргументов, несуществующий `--settings`, `--workers 0`, `--budget 0`, `--timeout 0` — rc 2.

## Замечания для следующего агента

- Роутер: `--settings ~/.claude/skyori.settings.json`; в файле токен — не выводить содержимое целиком, маскировать ключи с TOKEN/KEY/AUTH. Слот `sonnet` = GLM-5.3-Flash, `haiku` = Qwen3-Coder-Next (имя в файле другое, см. выше).
- Через роутер обязательно поднимать `--budget` (счётчик CLI без тарифа и почти без кэша) и `--timeout` (GLM ~240 с на вызов, бывает больше 420).
- Qwen3-Coder-Next для этой задачи отвергнут замером: дописывания, дубли из контекста, свёрнутые перечисления. Не возвращаться без новой модели в слоте.
- `pkill -f <шаблон>` из Bash убивает и саму команду, если шаблон входит в её текст — останавливать процессы по PID.
- Carry-forward:
  - Thinking у haiku не выключать ради скорости: без него выбрасываются целые фразы (замер в комментарии у `THINKING`). `--effort` на haiku не действует, `MAX_THINKING_TOKENS` работает только как 0.
  - Лимит подписки реален: полный эталон на haiku — ~6 вызовов по 15–25k выходных токенов, однажды упёрлись в 429. Эксперименты экономить.
  - Долгие прогоны запускать в фоне или с таймаутом Bash 600000.
  - Отчёт потерь — предупреждение, не гейт и не ретрай; паразитов не доводить — решения пользователя.
  - Разброс модели между прогонами больше эффекта правки промпта: выводы — по нескольким прогонам и воспроизводимости дефекта.
  - Примеры для промпта сверять с исходником: difflib на перестановках даёт ложные «выпадения» и «вставки»; смотреть и difflib, и мультимножественный отчёт потерь.
  - `FILLERS` вычитаются целиком по числу вхождений — смысловая потеря таких слов в отчёт не попадёт, сознательный размен.
  - `_continued` во входе целиком строчными опускает регистр и у имени собственного в начале шва — осознанный размен.
  - Константы для экспериментов — через флаги или подмену при импорте, не правкой файла.
  - Стоимость сравнивать в одном состоянии кэша: правка `chunk-prompt.md` сдвигает префикс.
  - Лекция публичная — цитаты допустимы в промпте и документах задачи; приватные записи — нет.
  - Вне скоупа по анализу: `--bare`, тесты с фейковым `claude -p`, смена пути запуска в transcript-cleanup.
