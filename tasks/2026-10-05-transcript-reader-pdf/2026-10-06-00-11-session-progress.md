## Что сделано в этой сессии

### Новый скрипт `transcript-cleanup/reader_pdf.py`
- Импортирует `cleanup_transcript.py` как модуль (`ct`): `Replica`, `LINE_RE`, `call_claude`, `part_key`/`load_part`/`save_part`, `MAX_RETRIES`, журнал вызовов. `chunk_replicas` и `sentence_starts` не понадобились.
- CLI: `reader_pdf.py <file.clean.txt> [--chapters <file>] [-o out.pdf] [--title T]`. Выход по умолчанию — `<src>.with_suffix(".pdf")` (для `x.clean.txt` это `x.clean.pdf`), рядом `<out>.html`, ответы модели — `<out>.parts/`. Существующий PDF не перезаписывается (rc 2). Заголовок по умолчанию — имя файла без `.txt`/`.para`/`.clean`, дефисы и подчёркивания заменены пробелами (`default_title`, `reader_pdf.py:541`).
- `parse_chapters` (`reader_pdf.py:147`): ведущий таймкод `H:MM:SS` / `HH:MM:SS` / `MM:SS`, название очищено от оформления в начале (`TITLE_LEAD_RE` — всё, что не `\w`, не кавычка и не открывающая скобка). Строка без таймкода и голый таймкод без названия пропускаются: со страницы выпуска вместе с главами копируются длительности соседних выпусков. Неубывающие таймкоды или пустой результат дают `ValueError`, в CLI это rc 2.
- `parse_transcript` (`reader_pdf.py:173`) — отдельная функция: строки продолжения становятся абзацами через `\n`. `ct.parse_transcript` не тронут. `paragraphs(r)` — `r.text.split("\n")`.
- `locate` (`reader_pdf.py:209`) находит место главы:
  - реплика — последняя, начавшаяся не позже таймкода; если до начала следующей не больше `SNAP_S = 5` с, то следующая;
  - абзац 0, если в реплике один абзац или до её начала не больше `SNAP_S`;
  - иначе оценка интерполяцией: доля времени между началом этой реплики и следующей переводится в долю символов. Для последней реплики конец оценивается по среднему темпу транскрипта;
  - кандидаты для модели — ±`ANCHOR_WINDOW = 3` абзаца вокруг оценки.
- `pick_paragraphs` (`reader_pdf.py:241`): один вызов haiku на все главы внутри реплик. В payload: название, `prev_title`/`next_title`, спикер, оценка (`estimate`) и кандидаты с номерами абзацев 1-based. Ответ `{"anchors":[{n, paragraph}]}`; номер не из кандидатов или пропущенная глава — ретрай с `retry_notice`. Ответ кэшируется в `anchors.json`.
- `anchor_chapters` (`reader_pdf.py:314`): если модель исчерпала ретраи, заголовок ставится по оценке, а в stderr идёт предупреждение. Место раньше предыдущей главы подтягивается к предыдущей.
- `model_sections` / `_call_sections` (`reader_pdf.py:355`, `:386`): без глав размечает sonnet одним вызовом. Единицы — все абзацы всех реплик с таймкодом и спикером, плюс `duration_minutes`. Проверки ответа: первый раздел с 1, номера строго растут и не выходят за диапазон, названия непустые; иначе ретрай. После исчерпания попыток — rc 1. Ответ кэшируется в `sections.json`. У раздела, начатого внутри реплики, времени в заголовке нет.
- `render_html` (`reader_pdf.py:461`):
  - h1 и пометка об источнике разделов: «главы от авторов» или «предложены моделью»;
  - `<nav>` с оглавлением (ссылки `#sN` и таймкоды), после него разрыв страницы;
  - `h2` разделов; у каждой реплики строка `meta` с таймкодом и спикером;
  - после заголовка внутри реплики повторяется «спикер, продолжение»;
  - текст абзацев реплик — только в `<p>` без класса: по этому признаку тесты сверяют текст;
  - CSS (`reader_pdf.py:436`): A4, правое поле 45 мм под заметки, номер страницы через `@page @bottom-center`, шрифты PT Serif / Noto Serif.
- `print_pdf` (`reader_pdf.py:511`): `--headless --disable-gpu --user-data-dir=<tmp> --no-first-run --no-pdf-header-footer --generate-pdf-document-outline --print-to-pdf=...`, URL через `Path.as_uri()`. Временный профиль обязателен: с профилем по умолчанию запуск уходит в открытый Chrome. Браузер ищется среди `google-chrome`, `google-chrome-stable`, `chromium`, `chromium-browser`.
- `main` (`reader_pdf.py:556`):
  - нет браузера — HTML, «PDF не собран» в stderr, rc 0, в stdout путь к HTML, `.parts` удаляется;
  - печать упала — rc 1, HTML и `.parts` остаются;
  - успех — путь к PDF в stdout, `.parts` удаляется.

### Промпты

## Замечания для следующего агента

- Конфиденциальность: в фикстуры и документы задачи не переносить названия выпусков, имена гостей, названия глав и пути к локальным записям. Фикстура `podcast.*` полностью выдуманная.
- Главы реальных выпусков снимались со страницы через Playwright: страница рендерится JS, WebFetch видит только заголовок. Playwright MCP кладёт снимки в `.playwright-mcp/` в cwd. Эту папку в корне репо удалили, при повторе удалить снова.
- Правило «глава в реплике без абзацев — заголовок перед репликой» подтвердилось на реальных данных (главы на вопросе ведущего). Не менять на «ближайшее начало реплики».
- `parse_transcript` в `reader_pdf.py` намеренно отдельный от `ct.parse_transcript`: тот склеивает строки пробелом для фаз 1–2, и это поведение трогать нельзя.
- Отсутствие Chrome — rc 0 с предупреждением и путём к HTML в stdout, а не отдельный код. Так решено при реализации: stdout всегда называет то, что реально собрано.
- Модели: привязка — haiku (`ANCHOR_MODEL`), разметка — sonnet (`SECTIONS_MODEL`). Чанкование разметки не понадобилось: 117 тыс. символов ушли одним вызовом.
- Тесты CLI сужают `PATH` до tmp/bin, поэтому шебанг подделок требует симлинк `python3` там же. Без него поддельный `claude` не запустится.
