# Transcript Cleanup

Чистит диаризованный транскрипт вида `[HH:MM:SS] [SPEAKER_XX] текст` (выход `cli/diarize.sh`): подставляет имена вместо `SPEAKER_XX`, исправляет ASR-ошибки терминологии, расставляет пунктуацию. Каркас — таймкоды и метки — не меняется; реплики не удаляются, не склеиваются, не разрезаются.

Двухфазная схема, обе фазы — headless `claude -p --tools "" --json-schema` (JSON в / JSON out, без инструментов):

1. Карта спикеров (sonnet): скрипт детерминированно сужает скелет до сигнальных реплик (содержащих обращения из таблиц контекст-файла, следующая после каждой такой, плюс первые реплики каждого спикера), и sonnet строит по нему карту `SPEAKER_XX → имя` с опорами (обращение + ответ, вопрос к отсутствующему, самопрезентация). Спикер без опоры остаётся `SPEAKER_XX`. Подстановка имён — детерминированная замена строк в скрипте: один `SPEAKER_XX` — одно имя на весь выход.
2. Чистка текста (haiku): чанками по ~40 реплик, реплика — атом. Через модель проходит только текст реплик; таймкоды и метки сшивает скрипт.

## How to run

Скрипт самодостаточен (stdlib), скилл — тонкая обёртка. Разрешить путь двумя literal-lookup'ами и запустить:

```bash
SCRIPT="$(realpath .claude/skills/transcript-cleanup/cleanup_transcript.py 2>/dev/null \
  || realpath "$HOME/.claude/skills/transcript-cleanup/cleanup_transcript.py" 2>/dev/null)"
python3 "$SCRIPT" "<source>" "<context-file>" ["-o" "<output>"] ["--yes"]
```

Никаких `find` и глобов — два literal `realpath`, чтобы статический анализатор пермишенов не переспрашивал. Оба не нашлись — скилл не установлен, сообщить пользователю.

- Интерактивный прогон (по умолчанию): скрипт печатает карту спикеров с опорами и спрашивает stdin — принять / править руками / выйти. Работает только в терминале.
- Из сессии Claude (stdin не tty): только с `--yes`, иначе скрипт откажется с подсказкой. После прогона показать пользователю карту из stderr и выходной файл.
- Выход по умолчанию — `<source-stem>.clean.txt` рядом с исходником; существующий файл не перезаписывается (rc 2).
- Прогресс и дельта длины текста — в stderr; путь к выходу — единственная строка stdout.

## Context file

Маркдаун свободной формы, читается LLM обеих фаз. Единственная часть, которую скрипт парсит, — таблицы обращений: маркдаун-таблицы, у которых заголовок первой колонки содержит слово «Обращение» (например «Обращение в речи»). Их левая колонка даёт словарь обращений для предфильтра сигнальных реплик фазы 1; варианты пишутся через запятую («Аня, Анна»). Секции:

- Спикеры: таблицы «Обращение в речи → Имя для транскрипта» по сторонам (наша / заказчик); правила различения тёзок по темам.
- Глоссарий: канонические аббревиатуры; термины латиницей в каноническом виде; пары «как распозналось → как писать»; спорные пары с пометкой «проверять по аудио».

Образец структуры — синтетическая фикстура `tests/fixtures/project-context.md` (выдуманные проект, люди, термины). Реальные контекст-файлы приватны и в репо не попадают.

## Policy: что можно править в тексте

- Пары глоссария «как распозналось → как писать»; англицизмы — латиницей в каноническом виде; латинизированный кириллический сленг (склоняемая латиница — «в Virtualke» — сопоставляется с парами через границу скрипта); очевидные омофоны малой редакционной дистанции.
- Любая пунктуация и заглавные; разбивка слипшегося потока на предложения.

Чего нельзя: пересказ, сокращения, «улучшение» стиля; удаление слов-паразитов; нормализация обращений внутри реплик («Аня» остаётся «Аня» при метке «Анна Соколова …»); спорные пары; склейка/удаление/разрез реплик. Полный текст политики — `chunk-prompt.md`, правила карты — `map-prompt.md` (оба лежат рядом со скриптом).

## Верификация

- Каждый чанк: длина массива == числу реплик, пустых строк нет; расхождение — ретрай (кап 2).
- Финал: число реплик, таймкоды по порядку и метки выхода == входу с точностью до детерминированной подстановки. Совпало — rc 0, расхождение — rc 1, выход не записывается.
- Дельта длины текста — мягкий ориентир в stderr, не гейт: большая дельта — повод выборочно проверить реплики глазами.

## When NOT to use

- Монолог без спикеров (лекция, видео), нужна статья с неизменными словами — это `formatting-transcript`.
- Нужна суммаризация или конспект — чистка не сокращает.
- Нет контекст-файла — он обязателен: без таблиц обращений имена не выводятся, без глоссария нечего исправлять. Предложить пользователю собрать минимальный (таблица спикеров + пары ошибок из его проекта).

## Failure modes

| Симптом | Значение | Действие |
|---|---|---|
| rc 1, stderr «ВЕРИФИКАЦИЯ: …» | Каркас выхода разошёлся с входом | Не должно случаться (каркас не проходит через модель); если повторилось — сообщить, приложив stderr |
| «исчерпаны N попыток» | Чанк или карта спикеров упали 3 раза подряд | Перезапустить; повторится на том же месте — посмотреть реплику/чанк, возможно нетипичная структура |
| Карта опознала не всех | Нет опор в содержании | Это ожидаемо: правка карты руками в интерактивном режиме (e) или прогон с --yes и ручная правка меток после |
| Обращение к человеку есть в тексте, а его метка не опознана | Диаризация склеила передачу слова и ответ адресата в одну реплику — связка «обращение → следующая реплика другого спикера» невозможна | Ограничение входа, не баг: править метку руками после прогона |
| rc 2 «stdin не tty» | Интерактивный запуск без терминала | Запустить с --yes или из терминала |
